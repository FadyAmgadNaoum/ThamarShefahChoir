# Choir Management System ("كورال ثمر شفاه") — Implementation Roadmap

This document outlines the step-by-step technical implementation plan for building and deploying the production-ready system on Cloudflare Workers, Cloudflare D1, and Cloudflare R2[cite: 2].

---

## Technical & Architectural Mandates

1. **Default Language & Locale:** Egyptian Arabic (`ar-EG`) is the default and primary language across all user-facing interfaces, forms, toasts, validation errors, and statuses[cite: 2]. English (`en`) is maintained strictly as an optional secondary fallback[cite: 2].
2. **Infrastructure Target:** Cloudflare Free Tiers (Workers, D1 SQLite, and R2 Object Storage)[cite: 2]. Zero paid third-party dependencies[cite: 2].
3. **Security Model:** Server-authoritative architecture[cite: 2]. All GPS calculations, check-in time windows, role evaluations, point additions/deductions, and financial balances are validated on the backend[cite: 2].
4. **Data Integrity:** Historical data and quarterly rules are immutable; closed quarters are never retroactively modified[cite: 2].

### Phase 4: Server-Authoritative Attendance Engine
- [x] Build `/api/attendance/check-in` route:

    $$\text{distance} = 2r \arcsin\left(\sqrt{\sin^2\left(\frac{\Delta \phi}{2}\right) + \cos(\phi_1)\cos(\phi_2)\sin^2\left(\frac{\Delta \lambda}{2}\right)}\right)$$

- [x] Implement arrival classification engine:

  - `EXTREME_LATE` (تأخير حرج)[cite: 2]
